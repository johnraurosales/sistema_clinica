# Sistema de Clínica

Proyecto backend desarrollado con Django REST Framework para gestionar pacientes, médicos y citas médicas.

## Tecnologías utilizadas
- Python y Django
- Django REST Framework
- PostgreSQL
- Docker
- JWT
- AWS S3
- Bruno
- Render

## Funcionalidades
- Registrar, consultar, actualizar y eliminar pacientes.
- Gestionar médicos y sus especialidades.
- Registrar y actualizar citas médicas.
- Cambiar el estado de las citas.
- Subir fotografías de médicos a AWS S3.
- Iniciar sesión mediante JWT.
